Questions

Which devices does it work on?
Android E Ink readers running Android 9 or later. It’s built for the Crema Pebble and is in use on the Meebook E6, Kyobo sam 7 mono, BOOX Leaf, Poke3 and Palma, iReader Ocean 5 Pro and Tango, Viwoods AiPaper Mini and more. On other screen sizes it scales to the same proportions. It can’t run on devices that don’t install Android apps, such as Kindle or Kobo readers.
Is it free?
Yes, and there are no ads. You can use it freely for noncommercial purposes (PolyForm Noncommercial 1.0.0).
How do I install it?
Download the APK from GitHub Releases, copy it to your device and tap it in a file manager. Allow “install unknown apps” the first time. Then set Pebble Desk as your home app in its Settings › Apps › Default home app. Later versions install from Settings › About › Update.
Why does it need the accessibility permission?
To recognize the book you open in a reading app. It only receives the screens of supported reading apps and doesn’t look at any other app. Reading time comes from Android’s Usage access. You can use it as a launcher without turning either on.
Where is my reading history stored?
Only on your device; nothing is sent anywhere. The internet is used only to search covers (YES24) and to check for new versions (GitHub). Uninstalling the app deletes the history too.
